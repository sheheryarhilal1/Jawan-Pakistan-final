# ◈ NEXORA — AI Powered E-Commerce Customer Intelligence System

NEXORA is an AI-powered e-commerce analytics platform built for customer intelligence, business analytics, churn prediction, and sentiment analysis.

The system combines **Python, Streamlit, Pandas, SQLite, Machine Learning, Deep Learning, and NLP** to transform e-commerce data into actionable business insights.

## 🚀 Key Features

- 📊 Interactive business intelligence dashboard
- 💰 Revenue and order performance analysis
- 👥 Customer and product analytics
- 🌍 Customer geography analysis
- 🎯 AI-powered customer churn prediction
- 💬 Customer review sentiment analysis
- 🗄️ SQLite-based e-commerce database
- 🤖 Machine Learning / Neural Network integration
- 📈 Interactive visualizations
- 🌙 Premium dark glassmorphism interface

## 🛠️ Technology Stack

- **Python**
- **Streamlit**
- **Pandas**
- **NumPy**
- **SQLite**
- **Joblib**
- **Machine Learning**
- **Neural Networks**
- **NLP**
- **Data Visualization**
